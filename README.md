## 📌 Projects

### 🏠 홀가(家)분
> 시니어 대상 부동산 다운사이징 플랫폼 · 팀 캡스톤 프로젝트 (2026.07 ~ )
> `Vue 3` `Spring Legacy` `MyBatis` `MySQL`

보유 주택을 정리하고 더 적합한 집으로 이주하려는 시니어를 위해, **설문 → 추천 매물 확인 → 매물 비교 → 최종 선택 → 금융상품 추천 → 분석 보고서(PDF)** 로 이어지는 단일 플로우를 설계한 서비스입니다.

**담당 역할**
- 추천 매물 목록/상세 화면 개발 및 찜(관심 매물) 기능 구현
- 취득세·중개보수 실시간 계산 로직 구현 (심플택스 기준 원 단위까지 검증)
- 공공데이터 API 연동 데이터 파이프라인 구축: 국토부 실거래가(11만여 건), CCTV, 전통시장, 대형마트, 행정복지센터, 은행, 공원, 약국(좌표 기반 Haversine 반경 매칭)
- 실거래 데이터 75.6% 중복 발견 → `ROW_NUMBER() OVER(PARTITION BY ...)` 기반 중복 제거 로직 적용
- 평가 점수 산정 기준의 법령·공공연구 근거 조사 및 문서화

**Repo**: https://github.com/orgs/PJT29-3team
